# EddaStore Brand Kit — Source of Truth

هذا الملف هو المرجع البصري الأعلى أولوية لكل واجهات EddaStore، بما فيها Admin. إذا تعارض أي لون أو خط أو نمط في الواجهة الحالية مع هذا الملف، فاعتمد Brand Kit وحدّث واجهة Admin لتتوافق معه. لا تنقل هوية مشروع آخر ولا تستخدم ألوانًا عشوائية.

## 1. شخصية العلامة

- المجال: متجر تقني محلي احترافي لمنتجات وإكسسوارات الكمبيوتر واللابتوب.
- الشخصية: موثوقة، حديثة، هادئة، دقيقة، مرتبة، عملية.
- الواجهة عربية أولًا وباتجاه RTL. أسماء الموديلات والعلامات التجارية تبقى بلغتها الأصلية عند الحاجة.
- الانطباع المطلوب: متجر تقني مميز، وليس قالب Admin مجانيًا أو لوحة Bootstrap افتراضية.
- الأولوية للوضوح والسرعة وسهولة إدارة البيانات، لا للزخرفة.

## 2. الألوان المعتمدة

استخدم CSS custom properties مركزية بدل تكرار القيم في الصفحات.

- Forest / Primary: `#26372D` — اللون الأساسي والعناصر الرئيسية.
- Deep Forest / Hover: `#1E2B23` — حالات hover والعناصر الداكنة.
- Cream / Canvas: `#F4EBDD` — خلفيات دافئة خفيفة حيث تناسب.
- White / Surface: `#FFFFFF` — البطاقات والنماذج والجداول.
- Muted Gold / Accent: `#C5A56A` — إبراز محدود للأجزاء المهمة فقط.
- Charcoal / Main Text: `#202522` — النصوص الأساسية.
- Muted Text: `#737B74` — النصوص الثانوية.
- Border: `#E5E2D9` — حدود هادئة.
- Success: أخضر مفهوم ومتوافق مع الهوية.
- Warning: كهرماني واضح.
- Danger: أحمر واضح ومخصص للأخطاء والحذف.

لا تجعل اللون الذهبي خلفية كبيرة أو لونًا لكل الأزرار. لا تستخدم تدرجات لونية كثيرة أو ألوان neon.

## 3. الخطوط

- العربية: `Tajawal` كخيار أساسي؛ يمكن استخدام `Cairo` فقط إذا كان مثبتًا بالفعل ويحقق اتساقًا أفضل. اختر خطًا واحدًا متسقًا للواجهة بدل المزج العشوائي.
- الإنجليزية والأرقام وأسماء الموديلات: `Inter` عند توفره، مع fallbacks آمنة.
- حافظ على وضوح الأرقام والأسعار وSKU والأكواد.
- لا تضف تحميلًا خارجيًا جديدًا قبل فحص الخطوط الموجودة بالمشروع.

## 4. الشعار والاستخدام

- استخدم اسم العلامة الموجود فعليًا في المشروع: `EddaStore` مع العلامة/الأيقونة المعتمدة حاليًا.
- لا تستبدل الاسم أو الشعار أو تخترع شعارًا نصيًا جديدًا.
- حافظ على مساحة تنفس حول الشعار، ونسبة أبعاده، وتباينه.
- لا تستخدم Emoji كشعار أو كأيقونات أساسية.
- إذا لم يوجد ملف شعار صالح، استخدم الموجود كما هو مؤقتًا وسجّل ذلك في التقرير؛ لا تنشئ علامة بديلة من تلقاء نفسك.

## 5. الشكل العام

- خلفية الصفحة هادئة وفاتحة؛ مناطق العمل والبيانات على أسطح بيضاء.
- زوايا مستديرة باعتدال ومتسقة؛ تجنب أن يصبح كل عنصر pill أو شديد الاستدارة.
- ظلال خفيفة جدًا ومحدودة؛ الحدود والمسافات تقوم بالعمل الأساسي.
- كثافة معلومات متوازنة: لوحة الإدارة تحتاج كفاءة ومسحًا بصريًا سريعًا، لا فراغات ضخمة ولا تكديسًا.
- الأيقونات من المكتبة الموجودة في المشروع إن وجدت، بأسلوب وحجم موحدين.
- تجنب التأثيرات الحركية المبالغ فيها، الزجاجية Glassmorphism، والـ gradients الزخرفية.

## 6. قاعدة فضّ التعارض

ترتيب الأولوية:
1. هذا Brand Kit.
2. `ADMIN_UI_UX_STANDARD.md`.
3. الأنماط المفيدة الموجودة بالمشروع.
4. اجتهاد Codex.

يجوز إعادة تصميم Admin Layout وCSS الإداري الحالي إذا لزم لتحقيق هوية متماسكة. لا تغيّر Store layout أو صفحات Store في هذه المرحلة، ولا تغيّر منطق الأعمال لمجرد تحسين الشكل.
