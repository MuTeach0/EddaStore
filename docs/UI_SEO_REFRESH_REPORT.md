# تقرير تحديث واجهات EddaStore وSEO

## نطاق التحديث
تم تحديث واجهات المتجر ولوحة الإدارة بالاعتماد على `docs/EDDASTORE_BRAND_KIT.md`، مع الحفاظ على Controllers وServices وModels وقاعدة البيانات ومنطق الطلبات الحالي.

## ما تم تغييره

- توحيد الواجهة مع ألوان الهوية: Forest `#26372D`، Deep Forest `#1E2B23`، Cream `#F4EBDD`، Gold `#C5A56A`، مع Tajawal والحدود والمسافات المتناسقة.
- إعادة ترتيب روابط التنقل في Layout المتجر وإزالة الروابط المكررة أو التي كانت توحي بصفحات غير موجودة مثل «قصتنا» و«الأقسام» كرابط منفصل مكرر.
- إضافة زر واتساب عائم دائري بلون أخضر، مع تأثير بسيط قابل للإيقاف عند تفضيل تقليل الحركة، والرابط `https://wa.me/201002270587` للرقم `01002270587`.
- تحديث الصفحة الرئيسية، كتالوج المنتجات، تفاصيل المنتج، السلة، إتمام الطلب، المفضلة، وصفحات التواصل والأسئلة الشائعة وسياسة الخصوصية وصفحة الخطأ.
- استبدال بيانات تواصل تجريبية مثل البريد `support@eddastore.local` وساعات العمل غير المؤكدة بوسيلة التواصل المعروفة فقط.
- إزالة العبارات الداخلية الموجهة للمطورين من صفحات الإدارة، وتحسين النصوص الفارغة والتنبيهات.
- ترجمة حالات الطلبات المعروضة من الإنجليزية إلى العربية دون تغيير القيم المخزنة أو منطق الحالة.
- ربط أزرار المفضلة بإجراءات فعلية بدل أزرار لا تنفذ شيئًا، وتوضيح أن CTA بطاقات المنتجات يفتح التفاصيل ولا يضيف المنتج مباشرة إلى السلة.
- تعديل نموذج ترتيب المنتجات ليحافظ على البحث والتصنيف والماركة عند تغيير الترتيب.
- تحسين تجاوب الواجهات على الهاتف، وتباين العناصر، وحالات التركيز للوحة المفاتيح، وتفضيل تقليل الحركة.
- إضافة عناوين ووصف SEO، وCanonical URL، وOpen Graph، وبيانات منظمة للعلامة والمنتج، و`noindex` للصفحات الخاصة مثل الحساب والسلة وإتمام الطلب والمفضلة ولوحة الإدارة.
- الإبقاء على صفحات إدارة المنتجات والطلبات والعملاء والأقسام والماركات والكوبونات والتقييمات والمخزون والتقارير، مع تحسين القشرة البصرية المشتركة بدل حذف وظائف الإدارة.

## أهم الملفات المعدّلة

- `Views/Shared/_Layout.cshtml` و`Views/Shared/_Layout.cshtml.css` و`Views/Shared/_LoginPartial.cshtml`
- صفحات `Views/Home` و`Views/Store` و`Views/Cart` و`Views/Checkout` و`Views/Wishlist`
- صفحات `Views/Account` كافة
- `Views/Shared/Error.cshtml`
- `Areas/Admin/Views/Shared/_Layout.cshtml` وصفحات Dashboard والطلبات والتقارير والإعدادات والأدوار والإشعارات والبحث
- `wwwroot/css/site.css` و`wwwroot/css/admin.css` و`wwwroot/css/account.css`

## التحقق
- تم فحص ملفات CSS المعدلة بأداة تحليل CSS؛ لم تظهر أخطاء parsing.
- تم فحص النصوص بحثًا عن بيانات التواصل التجريبية والعبارات الداخلية المعروفة، وإزالة ما عُثر عليه منها.
- لم يتم تشغيل `dotnet build` أو اختبار المتصفح لأن بيئة العمل الحالية لا تحتوي على أداة `dotnet`. لذلك يجب تشغيل البناء محليًا قبل النشر.
